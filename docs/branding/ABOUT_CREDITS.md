# Super Greenfoot About artwork

Created 2026-09-17 by Jordan Cohen for the Super Greenfoot remix.

The image is a new DrawSimple composition using the footprint from the
Greenfoot 3.9.0 source release (`GREENFOOT-RELEASE-3.9.0`, commit `6c1390e`)
at [k-pet-group/BlueJ-Greenfoot](https://github.com/k-pet-group/BlueJ-Greenfoot):
`greenfoot/resources/images/greenfoot-icon-256-shadow.png`. The editable
DrawSimple source is `SuperGreenfootAbout.dsimp` in this directory. A 1072 × 658
export is `SuperGreenfootAbout@2x.png`; the About dialog displays the 536 × 329
asset at `boot/src/main/resources/bluej/supergreenfoot-about.png`.

The artwork credits original Greenfoot creators Michael Kölling and Poul
Henriksen and identifies Jordan Cohen as the author of this independent remix.

The dialog displays the current application version and its existing
contributors panel separately from this image.
