# Super Greenfoot About artwork

Created 2026-09-17 and reworked 2026-09-23 by Jordan Cohen for the Super
Greenfoot remix.

The current artwork is `SuperGreenfootAbout-v2.dsimp` (editable DrawSimple
source) with its master export `SuperGreenfootAbout-v2@2x.png` (1072 × 658).
It follows the splash (`SuperGreenfootSplash-v2.dsimp`, see
[`SPLASH_CREDITS.md`](SPLASH_CREDITS.md)) and is **original artwork**: the
mark on the right is the Super Greenfoot logo from
[`logo/`](logo/LOGO_CREDITS.md), and the accent colour is that logo's emerald
(`#34D399`). No upstream Greenfoot image is incorporated. The About dialog
shows `boot/src/main/resources/bluej/supergreenfoot-about.png` (536 × 329) and,
on Retina screens, `supergreenfoot-about@2x.png` (the master export). The
dialog around it is styled to match (`.super-about` in
`bluej/lib/stylesheets/dialogs.css`).

The first version, `SuperGreenfootAbout.dsimp` / `SuperGreenfootAbout@2x.png`,
is kept for reference. It incorporated the upstream footprint image
`greenfoot/resources/images/greenfoot-icon-256-shadow.png` from the Greenfoot
3.9.0 source release (`GREENFOOT-RELEASE-3.9.0`, commit `6c1390e`) at
[k-pet-group/BlueJ-Greenfoot](https://github.com/k-pet-group/BlueJ-Greenfoot),
and is no longer shipped.

The artwork credits original Greenfoot creators Michael Kölling and Poul
Henriksen, identifies Jordan Cohen as the author of this independent remix,
and names the fork's source (github.com/MrCohen/SuperGreenfoot) and its base,
Greenfoot 3.9.0 from King's College London.

The dialog displays the current application version and its existing
contributors panel separately from this image.
