# Super Greenfoot splash artwork

Updated 2026-09-17 by Jordan Cohen for the Super Greenfoot remix.

The new splash artwork is based on the Greenfoot 3.9.0 source release
(`GREENFOOT-RELEASE-3.9.0`, commit `6c1390e`) from
[k-pet-group/BlueJ-Greenfoot](https://github.com/k-pet-group/BlueJ-Greenfoot).
It incorporates the upstream footprint image from
`greenfoot/resources/images/greenfoot-icon-256-shadow.png`. The composition,
wording, colors, and layout were created in DrawSimple; the editable source is
`SuperGreenfootSplash.dsimp` in this directory.

Greenfoot was created by Michael Kölling and Poul Henriksen. Super Greenfoot
is a modified remix by Jordan Cohen, and is not an official Greenfoot release.

The build stamps the current version onto the blank area beneath `VERSION`.
The two exported PNGs match the upstream splash sizes: 536 × 329 and
1072 × 658 pixels.
